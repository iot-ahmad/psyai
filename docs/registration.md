# توثيق صفحة تسجيل الدخول وإنشاء الحساب (PsyAI Auth)

إليك التوثيق النهائي المعتمد بناءً على الاتفاق وملاحظات التصميم:

---

### 1. نوع صفحة التسجيل وتخصيصها:
- **تم حصر الصفحة بالكامل للأفراد فقط** (مع إلغاء خيار أخصائي / شركة).

---

### 2. البيانات والحقول المعروضة في نموذج إنشاء الحساب:
1. **الاسم الأول** (First Name)
2. **اسم العائلة** (Last Name)
3. **البريد الإلكتروني (Gmail / Email)** (إجباري)
4. **رقم الهاتف** (Phone Number) (إجباري)
5. **الجنس** (قائمة منسدلة Dropdown: ذكر / أنثى)
6. **كلمة المرور** (Password مع زر إظهار/إخفاء)

---

### 3. التعديلات المعتمدة أخيراً:
- **حذف حقل/ملاحظة وصف الحالة للأخصائي من نموذج التسجيل:** سيتم توفير خانة "اوصف حالتك" لاحقاً عند حجز الجلسة واختيار الأخصائي المناسب لضمان خصوصية وسرعة التسجيل الأولي.
- **حذف جملة:** *"يتم إرسال كود التأكيد والتذكيرات عبر WhatsApp API أو SMS"*.
- **حذف الخط المشع والظلال العريضة:** اعتماد تقسيم مائل هندسي حاد، نقي، وأنيق بدون أي خطوط مشعة أو ظلال تفصل بين الشقين.
- **الالتزام الكامل بالهوية البصرية الرسمية لـ PsyAI:**
  - استخدام الشعار الرسمي `psyai.png` مع النص المعتمد `PsyaI`.
  - لوحة الألوان الرسمية: الخلفية الداكنة `--teal-deep: #1a2e2f` و `--teal-dark: #243d3e`، والتدرج الذهبي المعتمد للمنصة `--gold: #d4a843` و `--gold-light: #e0bc72`.
